# OdE comparison edition 02

English: `/OdE/test2/`; Italian: `/OdE/test2/it/`.

## Intent

Lead with the proposed qualification pilot, a tangible deliverable and project maturity.
The initial audience journey is now offer → illustrative Passport → relevant contact.
Researchers and investors have concise dedicated briefs. The previous detailed research
is retained as an evidence library, with separate routing, layout, components and source resolver.

## Data boundaries

No new operational capacity, laboratory partnership, accreditation, customer, result,
fundraising terms or production availability is asserted. Stage statements derive from
the existing dossier. Career details are explicitly self-declared. Research programme
costs remain internal planning estimates, not customer pricing or supplier quotations.

The interactive Passport's three cases are invented and labelled throughout. There
is no blanket acceptance decision, skin outcome prediction or simulated shelf life.
The missing-data case does not invent the missing result. TOTOX is calculated from
the stated example components (2 × PV + AnV). The Codex acidity reference is identified
as supplementary food-quality information and not a cutaneous safety threshold.

The earlier spectral simulator remains as a separately labelled supporting demonstration.
The original `/OdE/test` remains intact except for the previously authorised source fixes.
The host website and the original `/OdE` pages are not modified.
